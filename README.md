# AlexaAudio 🎵

Projeto para transmitir e controlar fluxos de áudio da rede local (PC, celular ou servidor) diretamente para dispositivos **Amazon Echo (Alexa)**.

---

## 🎯 Ideia Geral

Espelhar o conceito de reprodução via interface `AudioPlayer` da Alexa (popularizado por projetos como [alexa-youtube](https://github.com/ndg63276/alexa-youtube)), substituindo fontes de nuvem externas por um servidor local de streaming e controle.
